# Dynamic Login & Registration Webpage

## 📌 Features
- User Registration
- User Login
- Profile Page (About Me section)
- Account Deletion
- Responsive UI with Bootstrap 5
- Data stored in `users.json` / localStorage

## 🚀 Tech Stack
- HTML5
- CSS3 + Bootstrap 5
- Pure JavaScript
- AJAX (for future JSON server integration)
